# Directory

The directory service: the LDAP groups, the names and member status that the ASF writes into LDAP, the
LDAP audit log, and the people API that the other services read. It is one of the services that replace
[Whimsy](https://github.com/apache/whimsy). The plan is in
[apache/tooling-migration](https://github.com/apache/tooling-migration).

The code follows in pull requests.
